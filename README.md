## EcoMart - Eco-Friendly E-Commerce Website

EcoMart is a **front-end e-commerce website** designed to showcase and sell **eco-friendly and sustainable products**. The project combines a clean user experience, responsive layouts, and interactive JavaScript features to encourage environmentally responsible shopping.

This project demonstrates the practical use of **HTML, CSS, and JavaScript** to build a structured, multi-page e-commerce website. It is a front-end demonstration project and does not include a production backend, database, or real payment processing system.

## Live Demo

[View the live EcoMart website](https://ecomart-icc-is.netlify.app/)

## Project Overview

EcoMart provides a complete demo shopping experience where visitors can browse sustainable products, learn about the purpose of the brand, read supporting content, and interact with shopping features.

The project focuses on:

- Sustainability awareness
- Responsive web design
- Clean and accessible user interfaces
- Product discovery and shopping interactions
- Modular file organization
- Practical front-end development skills

## Pages Included

- **Home Page** - Introduces EcoMart, featured products, categories, and the brand's sustainability message
- **Products Page** - Displays the available eco-friendly product collection
- **Product Details Page** - Provides additional information about selected products
- **Cart Page** - Shows selected products and cart-related interactions
- **Checkout Page** - Provides a front-end checkout form experience
- **About Page** - Explains the purpose and values of EcoMart
- **Blog Page** - Shares sustainability and eco-friendly lifestyle content
- **Research Page** - Presents research and reference material
- **FAQ Page** - Answers common customer questions
- **Contact Page** - Provides contact information and a contact form interface
- **Team Portfolio Pages** - Introduces the project team members

## Features

- Eco-friendly product showcase

## How to Run the Project

### 1. Clone or download the repository

```bash
git clone https://github.com/Anamikalimbu/EcoMart.git
cd EcoMart
```

### 2. Open the project

Open `HTML/index.html` directly in a modern web browser such as Chrome, Edge, Firefox, or Safari.

For the best local development experience, serve the project with a static server, such as the VS Code Live Server extension.

### 3. Explore the website

Use the navigation bar to visit the product, cart, checkout, blog, research, FAQ, contact, and about pages.
